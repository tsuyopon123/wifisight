    Filter (space = AND, comma = OR)

    free text
    SSID, BSSID, vendor, AP name, security, generation
    ch:36 band:6
    Channel (or center channel) / band
    sec:wpa3
    Security label or AKM contains
    ssid:techconf
    SSID, exact match
    vendor: ap:
    Vendor / AP name contains
    phy:be w:160
    PHY mode / channel width (MHz)
    rssi:-70
    Signal at or above (dBm)
    rssi<-75 ch>=100 w>=80
    Compare signal, channel or width with < <= > >=
    !sec:open
    NOT: hide what the term matches
    band:5 sec:wpa3
    AND: every term must match
    ssid:"Free Wi-Fi"
    Quotes keep spaces in one term
